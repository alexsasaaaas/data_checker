Time Series Feature Detector (時間序列特性檢測工具)
本工具旨在提供自動化的時間序列診斷，透過六大維度分析數據的「體質」，幫助分析師在進入模型訓練（如 ARIMA, Prophet, XGBoost）前，先掌握數據的特性與潛在挑戰。

六大核心指標深度分析
1. 週期性強度 (Seasonality Strength)
分析邏輯：系統透過 FFT (快速傅立葉轉換) 找出數據中最強的波峰頻率，並利用 STL (基於 Loess 的季節趨勢分解) 將原始序列拆解為：趨勢 (Trend)、季節 (Seasonal) 與 殘差 (Residual)。

指標意義：

高強度：代表數據有明顯規律（如電網負載的每日循環）。建議使用支援季節性的模型（如 SARIMA）。

低強度：數據可能趨近隨機走勢，或週期不明顯。

理想狀態：若為週期性業務，指標應 > 0.3。

2. 稀疏率 (Sparsity)
分析邏輯：計算序列中「零值」或「缺失值 (NaN)」所佔的比例。

指標意義：

高稀疏 (例如 > 0.5)：這通常出現在低頻次交易或稀有事件中。這類數據不適合傳統的連續型回歸模型，可能需要轉換為「間歇性需求預測」模型。

理想狀態：越低越好，代表數據連續性佳。

3. 突發率 (Burst Rate)
分析邏輯：檢測序列中相鄰兩點的變化量（差分絕對值）。若變化量超過平均變動程度的 3 倍，則視為「突發」。

指標意義：

高突發率：代表數據含有大量脈衝（Spikes），可能是設備異常、促銷活動或感測器雜訊。這會嚴重干擾模型的收斂。

理想狀態：通常應低於 0.1。

4. 取樣頻率 (Sampling Frequency)
分析邏輯：計算時間戳記之間的眾數（Mode）間隔，判斷數據是屬於秒級、分鐘級還是日級。

指標意義：

高頻數據 (< 60秒)：容易包含大量的高頻雜訊，通常需要先進行降採樣（Downsampling）或平滑化。

不穩定頻率：若間隔不固定，會導致傳統時序模型失準。

5. 變異數穩定性 (Variance Stability)
分析邏輯：使用滾動視窗（Rolling Window）計算變異數，並比較最大與最小變異數的離散係數 (CV)。

指標意義：

不穩定 (CV 高)：代表數據存在「異方差性」，即波動隨著時間放大（常見於股票或爆炸性成長的流量）。

處理建議：若此指標過高，建議先對數據進行 Log 轉換 或 Box-Cox 轉換。

6. 平穩性 (Stationarity / ADF Test)
分析邏輯：使用 ADF (擴展迪基-福勒檢定) 檢測統計特性是否隨時間改變。判定 P-value 是否小於 0.05。

指標意義：

平穩 (P < 0.05)：數據的均值和變異數不隨時間漂移，可以直接進入大多數統計模型。

非平穩：數據具有趨勢。

處理建議：若非平穩，則必須進行「差分 (Differencing)」處理。
